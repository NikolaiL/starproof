Deployment review

Starproof Monsters

Deploy an ERC721 collection on Base. There is no mint price. Players pay transaction gas. The proof issuer verifies existing signed game receipts and authorizes one collectible per chip per monster world.

The issuer is immutable. A compromised issuer can authorize arbitrary encounters; changing it requires a new collection. Metadata is served by Starproof. Review the contract before deploying.
