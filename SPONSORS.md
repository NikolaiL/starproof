# Candidate Classic prize tracks

No sponsor integration is implemented or selected yet. The hardware signing core remains independent of these choices.

| Priority | Track | Work required beyond the current demo |
| --- | --- | --- |
| 1 | [Arkiv: Build on Arkiv, from scratch](https://ethglobal.com/events/mumbai/prizes/arkiv), $4,000 pool | Write ships, discoveries and action receipts to the current testnet and query them in gameplay. Document ownership, indexed attributes, expiration and why users need a shared queryable data layer. Supply the required `/arkiv/` judging files. |
| 2 | [Hedera: No Solidity Allowed](https://ethglobal.com/events/mumbai/prizes/hedera), up to two $1,000 awards | Use at least two native services through its SDK, e.g. HTS artifacts and HCS action receipts. Show a working testnet flow. A server enforcing hardware proofs is still a trusted component. |
| 3 | [ENSv2: Best Use](https://ethglobal.com/events/mumbai/prizes/ens), $7,000 pool | Use ship/captain namespaces and real delegated registry permissions on mainnet or Sepolia. Simple name labels are insufficient. |

[0G Physical AI](https://ethglobal.com/events/mumbai/prizes/0g) is conditional on adding substantive AI decisions, decision request IDs on 0G Storage, and safe-stop behavior. A hardware-signed game alone does not meet it.

[Anon-RPC](https://ethglobal.com/events/mumbai/prizes/ethereum-foundation) remains a separate project direction. No price-feed or generic signing prize should be assumed.

ETHGlobal allows three partner selections. Track requirements and payouts were checked November 6, 2026; verify the live pages before submitting. Classic reuse/AI disclosures are in README.md.
